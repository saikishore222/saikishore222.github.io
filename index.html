Projects

Wallet Sentinel

Rust, Axum, Helius, Next.js — demo   github

Solana wallet explorers show balances but don't tell you which tokens are bait. Wallet Sentinel scores every token in a wallet for spam and scam risk. It also detects address poisoning — when someone sends you a token from an address designed to look like one you've used before. On the test wallet: 22 of 24 tokens unverified, 17 dust, 2 sitting at 10k+ as bait.
